# 第II部 第4章 ブラックモデル

この章は、原稿の第II-4章『ブラックモデル』の React 版です。計算は R の HTTP API が **RiemannFinMath** で行います。原稿のコードを GaussQuant で動かした結果と同じ入力で照合しました。Black 76 の価格と Greeks、European put と American put の各エンジン、Sobol パス、Longstaff–Schwartz の価格・行使の内訳は、許容誤差の範囲で一致し、原稿の計算結果とも一致しています（`reconciliation/black/`）。

<BlackStatus />

> 入力値は原稿の例示的な値です。市場の気配値ではありません。疑似乱数のモンテカルロだけは、RiemannFinMath の乱数が QuantLib の Mersenne Twister と別なので、原稿の値とは標本誤差の範囲で異なります。

Black–Scholes–Merton（BSM）モデルは、株価が幾何ブラウン運動に従い、将来の株価が対数正規分布に従うと仮定します。Black（1976）はこの考え方を先物オプションに当てはめました。BSM は現物価格・金利・配当からフォワード価格を求め、Black 76 は観測したフォワード価格（先物価格）を直接入力します。どちらも、原資産価格は正で、その変化率が正規分布に従うという同じ仮定に立っています。

## II-4.1 ブラック–ショールズ–マートンとブラック76

リスク中立測度の下で、株価は

$$
dS_t = (r - q) S_t\,dt + \sigma S_t\,dW_t, \qquad F_0 = S_0 e^{(r - q)T}
$$

に従います。Black 76 の European call と put は

$$
C = D(0,T)\bigl[F_0 N(d_1) - K N(d_2)\bigr], \qquad P = D(0,T)\bigl[K N(-d_2) - F_0 N(-d_1)\bigr]
$$

$$
d_1 = \frac{\log(F_0/K) + \tfrac12 \sigma^2 T}{\sigma\sqrt{T}}, \qquad d_2 = d_1 - \sigma\sqrt{T}
$$

で、$K$ は行使価格、$D(0,T)$ は満期までの割引係数です。金利が決定論的なら同じ満期の先物価格とフォワード価格は一致するので、Black 76 は先物オプションにもフォワードのオプションにも使えます。

## II-4.4 モンテカルロ評価

### II-4.4.1 擬似乱数モンテカルロ評価

リスク中立評価では、オプション価格は満期 Payoff の割引期待値です。

$$
V_0 = D(0,T)\,E^Q\bigl[\max(F_T - K, 0)\bigr]
$$

多数の将来パスを生成し、各パスの満期 Payoff の平均を割り引きます。European call には解析解があるので、ここでの目的は、パスの期待値が Black 公式の価格に近づくことを確かめ、解析解のない商品に進む準備をすることです。標準誤差は、有限本数のパスによる推定の不確実性です。解析値との差が標準誤差と同程度なら、結果は統計的に整合的です。

<BlackControls which="mc" />

<McPanel />

Sobol 列は低乖離列なので、同じパス数でも擬似乱数より解析値に早く近づくことが多いものの、パスどうしは独立な標本ではありません。Sobol 列の標準誤差は、通常の意味では解釈できません。

### II-4.4.2 モンテカルロパスの可視化

フォワード価格は対数正規分布に従うので、どのパスも正の値をとり、満期価格の分布は左右対称になりません。

<McPathCharts />

### II-4.4.3 Black 過程の1パス

フォワード測度の下ではフォワード価格のドリフトがゼロなので、時間幅 $\Delta t$ ごとに

$$
F_{t+\Delta t} = F_t \exp\Bigl[-\tfrac12 \sigma^2 \Delta t + \sigma\sqrt{\Delta t}\,Z\Bigr]
$$

で更新できます。指数部の $-\tfrac12\sigma^2\Delta t$ は伊藤の補正項です。原稿は QuantLib の擬似乱数を取り出して手計算と比べました。ここでは RiemannFinMath の Sobol パスを、同じ Sobol 点の逆正規 $Z$ から手で計算したパスと比べます（Sobol 列の最初の点はどの次元も 0.5 で $Z = 0$ なので、2〜4 本目を示します）。差は、パス生成が使う逆正規の近似（QuantLib と同じもの）と R の `qnorm` の差です。

### II-4.6.2 ロングスタッフ–シュワルツ法

American オプションでは、行使できる各時点で、即時行使価値 $I(S_t) = \max(K - S_t, 0)$ と保有を続ける価値を比べます。Longstaff–Schwartz 法は、将来の割引キャッシュフローを原資産価格で回帰して継続価値を推定します。原稿と同じく 2 次多項式

$$
\widehat{C}(S_t) = \beta_0 + \beta_1 S_t + \beta_2 S_t^2
$$

を使い、即時行使価値が推定した継続価値を上回る時点で行使します。回帰と評価に同じパスを使うのも原稿と同じです。

<BlackControls which="lsm" />

<LsmPanel />

Longstaff–Schwartz の価格は、パス数、時間ステップ、基底関数、回帰誤差に依存します。原稿の条件では回帰と評価が同じパスなので、価格は上方に偏ります（同じ 12 時点で行使できる put を細かい木で評価すると約 6.0547。Riemann の比較資料 `comparison/chapters/ch08_options.qmd` による）。二項ツリーとの差をゼロにすることではなく、早期行使の判断をパスの上でどう近似するかを見るための計算です。

Black 76 と BSM は、原資産が対数正規分布に従うという共通の仮定を持ちます。この仮定は、金利がゼロやマイナスになる市場では直接使えません。これが Normal モデルや Shifted Black モデルを使う理由になります。
