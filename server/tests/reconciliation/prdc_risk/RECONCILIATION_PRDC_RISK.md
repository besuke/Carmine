# 第III部（自動微分・並列・分散による PRDC のリスク計算）の照合

- 照合日：2026-11-14（`results/session_info.txt`）
- 対象：LagrangeFinance III-7（`part3_enterprise_riemann/ch07_prdc_autodiff.qmd`）の PRDC。第III部の残り（III-2〜III-7）をまとめたページ
- 照合する側：API が実際に使う `server/R/prdc_risk_model.R` をそのまま読み込んで比べる
- 比べる相手：R で独立に書いた閉じた式（各クーポンをフロア＋FX のコールスプレッドとして評価）とその中心差分、Bump & Revalue、スレッド数・ジョブを変えた同じ計算、原稿の torch のコード（qmd から III-7.1〜7.3 の計算部分をそのまま読み込んで実行）
- 再実行：`npm run reconcile:prdc-risk`（参照値 `server/tests/golden/prdc_risk_golden.json` も書き直す）、`npm test`（`tests/prdcRisk.api.test.ts`）

## 入力

原稿 III-7.1 の説明用の値。想定元本 1億円、5年、年1回のクーポン min(8%, max(0, 2% + 80% × (S / 150 − 1)))、満期に元本を償還、FX スポット 150、FX ボラ 12%、各年の円金利 1.0〜1.8%、外貨金利 4.0〜3.2%（その年のあいだ一定）。

## 計算の分担

| 項目 | このページの計算 |
|---|---|
| 現在価値と全感応度（自動微分） | rmql `compute_prdc_value(paths = 0)`：FX デルタ・ベガと、カーブの各節点の感応度を1回の評価で返す。カーブは各年末の割引係数を対数線形でつないだもの（その年のフォワードが一定、原稿と同じ） |
| Bump & Revalue | 同じ関数を、スポット ±1e-4 × S、ボラ ±1e-4、各節点のゼロ金利 ±1bp で呼び直す中心差分（24回） |
| 原稿の定義（各年の金利）の感応度 | 自動微分の各節点の log 割引係数に対する微分から、dV/dr_j = −Σ_{k≥j} dV/dlogDF_k |
| モンテカルロ・スレッド | `compute_prdc_value(paths, seed, threads)`：パスごとの自動微分、スレッド数 1・2・4・8 |
| 分散（ジョブ） | `POST /api/prdc-risk/job` がシナリオのまとまりを1回ずつ閉じた式で評価する。ジョブの分割・送信・集約はブラウザ |

## 結果【実行照合済み】

6 項目が許容誤差内、5 項目は判定しない参考値（`results/prdc_risk_diffs.csv`）。

| 比べたもの | 最大差 | 許容誤差 |
|---|---|---|
| 現在価値：rmql の閉じた式 − R の独立な式 | 1.5e-8 円 | 1e-6 円 |
| 自動微分 − Bump & Revalue（FX デルタ・ベガ・カーブ節点 10） | 相対 6.2e-7 | 相対 1e-5 |
| 年ごとの円金利・外貨金利の感応度：自動微分 − 独立な式の中心差分 | 相対 1.2e-7 | 相対 1e-5 |
| モンテカルロ：スレッド数（1・2・4・8）による差 | 0 | 0 |
| ジョブで評価した値 − 1件ずつの評価 | 0 | 0 |

**許容誤差を 0 にしなかった項目**：自動微分と中心差分の差は、中心差分の打ち切り誤差。

**判定しない項目**：原稿の torch は乱数の違うモンテカルロ（20000本、antithetic なし）。現在価値は 104,242,624 円で、閉じた式 104,113,578 円との差は、rmql の同じ本数のモンテカルロの標準誤差 55,741 円の 2.32 倍（torch は antithetic を使わないので、その標準誤差はこれより大きい）。FX デルタ（torch 473,469、閉じた式 466,353）、ベガ、年ごとの金利の感応度も、モンテカルロの標本誤差の範囲の差。

**ブラウザでの確認**：45 シナリオを 5 件ずつ 9 ジョブに分け、2 本ずつ送ると全体 0.47〜0.52 秒。1 件ずつ 45 ジョブ・4 本ずつ送ると約 1.0 秒（往復が増えるため）。ワーカーは1台なので、同時に送っても計算は届いた順に行われる。

**途中で直したこと**：ジョブの実行図で、経過時間が短いあいだ目盛りの文字が同じになり、React のキーが重複していた。`LineChart` の目盛りのキーに位置の番号を加えた。
